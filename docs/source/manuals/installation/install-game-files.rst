==================
Install game files
==================

OpenFallout plays Fallout 3, Fallout: New Vegas and Tale of Two Wastelands from
the files of a copy of the games that you own. It includes none of their
content. How to point it at the ``Data`` folder of your copy is in
`Running OpenFallout on your own copy of the games
<https://github.com/OpenBethesda/OpenFallout/blob/master/docs/openfallout/playing.md>`_.
